# Sistema de Gestión de Calidad de Software (SGCS)

Sitio web educativo dedicado a la difusión de conceptos clave sobre la gestión de calidad del software, procesos de desarrollo (SDLC), modelos tradicionales y metodologías ágiles.

## Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3 (Variables, Flexbox y CSS Grid).
* **Interactividad:** JavaScript Moderno (ES6+ DOM Manipulation, Event Listeners).
* **Diseño:** Interfaz adaptativa (Responsive Web Design) con tema oscuro y acentos lavanda.

## Estructura del Sitio (7 Páginas)
1. **01. Inicio (`index.html`):** Portada principal con accesos rápidos a todas las secciones.
2. **02. Gestión de Calidad (`fundamentos.html`):** Conceptos, métricas y normas ISO (9126 / 25000).
3. **03. Procesos de Desarrollo (`sdlc.html`):** Ciclo de vida del software y modelos tradicionales.
4. **04. Metodologías Ágiles (`agiles.html`):** Manifiesto Ágil, Scrum Profundo, Kanban e ilustradores interactivos.
5. **05. Herramientas de Calidad (`herramientas.html`):** Comparador dinámico de metodologías y encuesta de preferencias metodológicas.
6. **06. Recursos y Aprendizaje (`recursos.html`):** Glosario, preguntas frecuentes (FAQ), enlaces de interés y ejercicios prácticos.
7. **07. Nosotros y Contacto (`nosotros.html`):** Presentación del equipo de desarrollo y formulario de contacto funcional.

## Funcionalidades Destacadas (JavaScript)
* **Comparador Interactivo:** Permite seleccionar múltiples metodologías para contrastar en tiempo real sus características (enfoque, roles, flexibilidad, documentación).
* **Encuesta Metodológica (Wizard):** Asistente paso a paso que evalúa los requerimientos de un proyecto para sugerir el marco de trabajo ideal.
* **Simulador Kanban:** Tablero interactivo con control de límite WIP (Work in Progress).
* **Navegación Maestro:** Sistema de menú lateral unificado desplegable en todas las páginas.
